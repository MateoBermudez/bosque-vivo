# ADR 0012: Modelo propio de visión como evolución futura

- Estado: aceptada

## Decisión
No se entrena un modelo propio de detección de cambio en este alcance (RF11). La evaluación de calidad de escena usa Gemini con salida estructurada y se valida contra etiquetas humanas. Queda como trabajo futuro, comparado contra el umbral simple de variación de NDVI.
